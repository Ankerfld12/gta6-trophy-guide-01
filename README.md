# Leonida Ledger — GTA VI Trophy Guide & Tracker

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, built for make.fun's “Build the best GTA 6 trophy guide” bounty (gta6-trophy-guide-01). Open it, and the whole list is in front of you: every trophy with its official name, description and grade, a guide to it in our own words with its sources named, a six-phase roadmap to the platinum, and a checklist that remembers your progress in the browser.

## What it does

- **The full official list** — all 55 trophies (1 platinum, 2 gold, 6 silver, 46 bronze) with the official names, descriptions and grades exactly as published.
- **A tracker** — tick trophies off as you earn them; progress is saved in `localStorage`, with a header summary (earned count, percentage, per-grade counts, platinum state), plus export to a JSON file, import back, and reset.
- **Filters and search** — by grade, by kind (story, collectible, combat, vehicle, exploration, social, misc), by status (all / earned / remaining / missable only), full-text search across names, descriptions and guides, and three sort orders. Mark-visible and clear-visible act on the current filter.
- **Spoiler mode** — story trophies' names and descriptions stay blurred until you earn them (the setting is saved too). Deep link: `#spoilers`.
- **A guide per trophy** — a short guide in our own words, the reasoning behind its missable judgement, its roadmap stage, and its sources, one click from each card. Deep link: `#trophy-<id>` (for example `#trophy-17`).
- **Roadmap to the platinum** — six phases ordered from the official descriptions, with hour figures labelled as the rough planning estimates they are, per-phase progress, and a missable watch: three trophies flagged, each with the wording its flag rests on, under an honest note that no official description states a point of no return. Deep link: `#roadmap`; `#filter-missable` shows just the flagged three.

## Run it

Any static file server with `app/` at its root works. This repository carries one:

```sh
node serve.ts          # PORT env var, default 8080
# then open http://localhost:8080
```

Opening `app/index.html` through a server is all it takes; the app loads only its own files (two JSON data files included) and works with the network off. There is no build step.

## Data and sources

- `app/data/trophies.json` — the official list, copied unchanged from the competition kit: names, descriptions and grades as PlayStation publishes them (the kit froze the list on 2026-11-18 from Exophase and PSNProfiles, the two agreeing on every name, description and grade).
- `app/data/guide.json` — this entry's own enrichment, generated by `build-guide.mjs`: each trophy's kind, roadmap stage, missable flag with its reason, a short guide in our own words, and its sources. Run `node build-guide.mjs` to regenerate it; the script validates that all 55 official ids are covered.
- Guide sources, named beside every trophy: the official PlayStation 5 trophy list for Grand Theft Auto VI (2026-11-18); PSNProfiles for the counts PlayStation tracks where a description gives none; Rockstar Games' official Grand Theft Auto VI page for the game's premise. No location, step or count is asserted beyond what those sources state, and the missable flags say plainly that they are judgements reasoned from the descriptions' wording.

## Layout

- `main.ts` — the entry program: copies `app/` and `screenshots/` to the output directory (`MAKEFUN_OUTPUT_DIR`, else `/output`) and writes `dossier.json` there with the kit's `buildDossier` under the bounty's gate caps.
- `vendor/makefun-frontend.ts` — the kit's library, copied unchanged, as the bounty requires.
- `app/` — the guide itself: `index.html`, `style.css`, `app.js`, `data/`.
- `screenshots/` — four renders of the running app, described in `shots.json`.
- `build-guide.mjs` — the generator for `app/data/guide.json`.
